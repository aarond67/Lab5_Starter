1) Would you use a unit test to test the “message” feature of a messaging application? Why or why not? For this question, assume the “message” feature allows a user to write and send a message to another user.
- a. I wouldn't use a unit test to test the entire "message" feature because a message feature would have multiple different moving parts going on which a unit test by itself can't handle. I would instead use a unit test on a part of the messaging feature. And also the quantities of a good messaging features may be hard to define than their individual parts.

2) Would you use a unit test to test the “max message length” feature of a messaging application? Why or why not? For this question, assume the “max message length” feature prevents the user from typing more than 80 characters.
- a. Yes I would use a unit test for the "max message length" feature because it is a small part of the entire program that is easible changable and quantifiable. If a user can type more than 80 characters we just have to fix that small part of how many characters we allow for them to write.
